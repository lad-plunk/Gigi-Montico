# Biography page offline preview

This folder is a review-only prototype. It does not modify the official biography pages.

Open one of these files directly in a browser:

- `biografia-preview.html` for Italian
- `biography-preview.html` for English

The preview reuses the production stylesheet and the existing Montico image, then adds preview-only CSS and JavaScript for the five-period career view and the artistic-phase cards. The period bars are based on the current 95-entry research register, while the text is an editorial presentation concept rather than a replacement for the full register.

The Italian version describes painting as Montico's principal continuous work while explicitly placing it within family, sport, friendships and community life. It also frames stylistic change as deliberate continuous research, with links to the period gallery and the Realismo Terminale virtual exhibition. The PDF link in the preview points to the current local interactive register. Before production implementation, review the narrative wording, period boundaries, artistic-phase labels, level of detail and the balance between professional career, family and territory.
