# 11 / 1000 web images

This folder contains website-only derivatives for the Italian `11 / 1000` project page.

- `M1000-*.webp`: faithful, uncropped WebP derivatives of the 11 exact canonical files recognized by Gigi Montico.
- `book-cover.webp`: optimized website cover thumbnail retained from the earlier RC7 rendering.
- `gold-frame-portrait.png` and `gold-frame-landscape.png`: transparent frame-v12 overlays used by the completed RC9 book and by the website presentation of the 11 recognized works.

The canonical PNG masters, frame sources, and project records remain in the read-only external project folder. Do not treat the WebP artwork derivatives as canonical files, rename IDs, alter colors, add signatures, or infer interpretative titles. All works remain `Senza Titolo`.
