# 11 / 1000 web images

This folder contains website-only derivatives for the Italian `11 / 1000` project page.

- `M1000-*.webp`: faithful, uncropped WebP derivatives of the 11 exact canonical files recognized by Gigi Montico.
- `book-cover.webp`: optimized thumbnail rendered from page 1 of the controlling RC7 review book; it is a preview only and does not imply publication approval.

The canonical PNG masters and project records remain in the read-only external project folder. Do not treat these compressed derivatives as canonical files, rename IDs, alter colors, add signatures, or infer interpretative titles. All works remain `Senza Titolo`.
