# Curated page images

This folder contains editorial images embedded directly by the bilingual HTML pages: homepage and social previews, self-portrait, selected gallery works, sustainability imagery, and other highlighted artworks.

Subfolders contain the `11 / 1000` website derivatives, Casa Montico tour, exhibition preview cards, and the 2026 Period I additions. These files are separate from the complete data-driven collection under `../archive/`.

Before changing a filename, search both language trees plus CSS and JavaScript for references. Keep captions and `alt` text meaningful and semantically aligned across languages.
