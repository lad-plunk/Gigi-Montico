# Review and press images

This folder stores imagery used by the books/reviews sections. Nine legacy uppercase-`.JPG` files sit directly here, while `recensioni-2026/` contains the newer 2026 review set.

Exact filename case matters on GitHub Pages. Confirm references in both `it/libri.html` and `en/books.html` before renaming, removing, or replacing a file. Treat review imagery as documentary source material and avoid altering it unless explicitly requested.
