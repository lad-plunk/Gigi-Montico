# Artwork archive media

This folder stores the full-resolution or web-ready artwork media used by the photo archive and virtual exhibitions. Four child folders correspond to the exhibition catalog collection slugs in `../data/archive.js` and `../data/archive.json`.

- `acquerelli-surrealisti/` (`AS`)
- `collezione-privata/` (`CP`)
- `arte-sostenibilita/` (`LS`)
- `digital-art-ai-support/` (`DA`)
- `montico-paintings/`: the separate 326-photo archive, with lightweight grid previews and higher-resolution lightbox derivatives.

Filenames are stable identifiers referenced by catalog or manifest path fields. Add, remove, or rename media only together with the corresponding synchronized data formats, and verify unique IDs, item count, and path existence afterward.
