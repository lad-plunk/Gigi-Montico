# Artwork archive media

This folder stores the full-resolution or web-ready artwork media used by the data-driven archive and virtual exhibitions. Its four child folders correspond to the catalog collection slugs in `../data/archive.js` and `../data/archive.json`.

- `acquerelli-surrealisti/` (`AS`)
- `collezione-privata/` (`CP`)
- `arte-sostenibilita/` (`LS`)
- `digital-art-ai-support/` (`DA`)

Filenames are stable identifiers referenced by catalog `path` fields. Add, remove, or rename media only together with both catalog formats, and verify unique IDs, item count, and path existence afterward.
