# Archive detail images

This folder contains 326 higher-resolution WebP derivatives loaded only when a visitor opens an archive photograph. Files are generated, not hand-edited, and correspond one-to-one with the technical IDs in `assets/data/paintings-archive.json`.

Regenerate them together with the `previews/` variants by running `10_Working/build_paintings_archive.py` against the external, read-only source folder.
