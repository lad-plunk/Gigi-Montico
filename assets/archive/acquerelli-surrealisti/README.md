# Surreal Watercolors archive (`AS`)

Contains 59 JPEG artwork images named `AS-0001.jpeg` through `AS-0059.jpeg` for the “Acquerelli Surrealisti / Surreal Watercolors” collection.

Metadata and public paths are controlled by `../../data/archive.js` and `../../data/archive.json`. Preserve the `AS-NNNN` naming sequence and do not infer titles, dimensions, or provenance from the image alone.
