# Private Collection archive (`CP`)

Contains 135 JPEG artwork images (`CP-0001` to `CP-0135`) for “Collezione Privata di Opere di Montico dal 1970 ad oggi / Private Collection of Montico's Works (1970-present).”

This is the largest catalog collection. Metadata and public paths are controlled by `../../data/archive.js` and `../../data/archive.json`; preserve sequential IDs, exact extensions, and filename case.
