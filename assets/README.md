# Shared website assets

This folder contains all assets shared by the Italian and English pages.

- `archive/`: full catalog artwork images, grouped by collection.
- `books/`: downloadable PDF publications.
- `css/`: shared site presentation.
- `data/`: artwork catalog data.
- `images/`: curated images embedded in editorial pages.
- `js/`: shared interaction and catalog-rendering code.
- `reviews/`: press and review imagery.

Relative asset paths are referenced throughout both language trees. Avoid renaming or moving files; if a path must change, update every HTML, CSS, JavaScript, catalog, sitemap, and metadata reference that uses it.
