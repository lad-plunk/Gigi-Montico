# English pages

This folder contains the 14 public English HTML pages. Each page has an Italian counterpart in `../it/`; the pair mapping is listed in the root `README.md`. `privacy.html` explains technical processing and the optional use of Google Analytics.

Pages share `../assets/css/site.css` and `../assets/js/site.js`. Archive and themed exhibition pages additionally load `../assets/data/archive.js` followed by `../assets/js/catalog.js`.

`11-1000.html` is the English counterpart of the finalized Italian project page. It currently links to the same authoritative completed Italian RC10 PDF; the older English DOCX draft is not published as a final edition.

When editing, keep navigation, metadata, canonical and `hreflang` URLs, structured data, footer details, asset paths, and the Italian counterpart aligned. English filenames are public URLs and should not be renamed casually.
